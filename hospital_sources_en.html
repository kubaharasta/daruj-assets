Blood Barometer Data Sources

App: Daruj

Author: Jakub Harašta

Last updated: September 18, 2026

The Daruj application operates as a non-commercial and non-profit project supporting non-remunerated blood donation in the Czech Republic. Current blood supply levels (blood barometers) are obtained through automated data collection (scraping) from publicly available official websites of individual transfusion stations.

Note: For some providers, data is available in a text format (exact percentages). For others, the app performs a visual analysis of available graphical elements, assigning a corresponding percentage value based on the state/color of the icon. Therefore, this data should be regarded as an approximate representation of the current status.

This data collection complies fully with the ethical and legal framework for handling public data. Furthermore, the system is equipped with an automatic check of the robots.txt file for each source website, fully respecting the access rules set for bots and search engine crawlers. All copyrights to the information belong exclusively to the respective medical facilities.
